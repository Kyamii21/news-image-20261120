One image that sums up the world news of Friday 20 November 2026: a
newspaper front page with a lead story (Russian missiles landing in NATO
Poland during the biggest November strike on Ukraine) and nine further
verified stories across diplomacy, justice, markets, Europe, the Middle
East, climate, disaster and US news — each with its exact figures.

## Files

- `entry.png` — the submitted image (1024×1024).
- `main.py` — standard-library entry program; copies `entry.png` to the
  output directory byte-for-byte.
- `draw_v3.py` — the Pillow renderer that draws `entry.png` (build-time
  only; the grader runs `main.py`).
- `preview-300.png` — 300px legibility preview.
- `NOTES.md` — the ten stories with their sources.

## Run

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
